# 🧶 Loop & Stitch

A full-stack web application for creating, organizing, managing and sharing crochet and amigurumi patterns.

## 🎯 About the project

Loop & Stitch is a personal software engineering project inspired by crochet and amigurumi pattern design.

The platform will allow users to create and manage structured crochet patterns, including materials, sections, rounds and project information.

The first pattern implemented in the application will be **Osito**, a crochet amigurumi bear.

## 🚀 Planned Features

### MVP

* Create crochet patterns
* Edit patterns
* Delete patterns
* View pattern details
* Search and filter patterns
* Manage pattern materials
* Manage pattern sections and rounds
* Add pattern images

### Future Features

* Material cost calculation
* Project and inventory management
* PDF pattern generation
* Visual pattern designer
* User authentication
* Public pattern sharing
* AI-assisted pattern creation
